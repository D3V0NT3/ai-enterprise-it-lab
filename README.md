# AI Enterprise IT Infrastructure Lab

## Overview

This project is a progressively developing enterprise IT lab designed to simulate the day-to-day responsibilities of an IT Support Technician, Infrastructure Technician and eventually an Infrastructure/Security Engineer.

The environment is built around a fictional company called Northstar Manufacturing.

Rather than completing isolated tutorials, the goal is to create a persistent business environment containing real users, endpoints, servers, networks and IT services.

Future versions of the project will integrate AI-powered fictional employees that generate realistic support requests and incidents.

## Current Environment

- Oracle VirtualBox
- Windows Server 2025
- Active Directory Domain Services
- DNS
- Windows domain: northstar.internal
- Domain Controller: DC01
- Internal lab network: 192.168.56.0/24
- DC01 internal IP: 192.168.56.10

## Learning Objectives

The project will progressively develop skills in:

- Windows Server administration
- Active Directory
- DNS and DHCP
- Windows endpoint support
- Networking
- Group Policy
- Microsoft 365 concepts
- PowerShell
- Asset management
- Monitoring
- Incident management
- Cybersecurity
- IT/OT network segmentation
- SCADA infrastructure awareness
- AI-assisted service desk simulation

## Progression

### Level 1 — Junior IT Support
Basic user, password, device and connectivity incidents.

### Level 2 — First Line Support
Active Directory, DNS, DHCP, Windows and permissions.

### Level 3 — Second Line Support
Group Policy, servers, access control and more complex troubleshooting.

### Level 4 — Infrastructure
VLANs, switches, firewalls, monitoring and service outages.

### Level 5 — Infrastructure Engineering
Multi-system incidents, automation and projects.

### Level 6 — Security
Threat detection, account compromise and incident response.

### Level 7 — IT/OT
SCADA connectivity, OT segmentation and specialist escalation.

## Current Status

The first domain controller has been deployed and the Northstar Active Directory environment is being built.
