# Northstar Manufacturing — Enterprise IT Infrastructure Lab

## Overview

This project simulates the IT environment of Northstar Manufacturing,
a fictional manufacturing company.

I am building this lab to develop practical skills relevant to IT support,
infrastructure, networking and cybersecurity roles.

The project follows requirements found in job descriptions I have reviewed,
including user support, incident management, Windows administration,
network troubleshooting, system maintenance and IT/OT support awareness.

## Current Status

Planning and preparation.

This is a fresh build. Configuration and testing will be documented
as each stage is completed.

## Planned Environment

- Oracle VirtualBox
- Windows Server 2025
- Windows 11 Enterprise
- Active Directory Domain Services
- DNS and DHCP
- Group Policy
- Shared folders and access permissions
- Windows event logging and monitoring
- A separate simulated manufacturing/OT network in a later stage

## Project Objectives

1. Deploy and document a virtual Windows environment.
2. Configure and verify network connectivity and name resolution.
3. Create a domain and join a Windows client.
4. Manage users, groups and access permissions.
5. Diagnose and resolve realistic support incidents.
6. Practise patching, backup restoration and change documentation.
7. Investigate simulated security events.
8. Explore IT/OT network segmentation through a lab simulation.

## Documentation Approach

Each completed stage will include:

- Objective and business purpose
- Configuration steps and settings
- Relevant screenshots
- Verification steps and actual results
- Problems encountered and how they were resolved
- Lessons learned

Support incidents will also include impact, investigation,
corrective action, user communication and escalation where appropriate.

## Scope

This is a personal learning environment using fictional business scenarios.
Completed exercises will be distinguished from planned features.

Microsoft 365, Intune and AI functionality are possible later extensions.
They are not implemented in this initial build.

## Evidence Handling

will remain outside the repository.
